# 权限矩阵功能说明

## 功能概述

权限矩阵页面提供了一个可视化的界面来管理系统中不同角色对不同资源的权限配置。

## 功能特点

### 1. 权限矩阵表格

- **行**：代表不同的角色（管理员、普通用户、访客）
- **列**：代表不同的资源（用户管理、数据查看、文件上传等）
- **交叉点**：表示该角色对该资源的具体权限级别

### 2. 权限级别

- **无权限 (none)**：无法访问该资源
- **只读 (read)**：只能查看，不能修改
- **读写 (write)**：可以查看和修改
- **完全控制 (full)**：所有权限包括删除

### 3. 默认权限配置

- **管理员 (admin)**：默认拥有所有资源的完全控制权限
- **普通用户 (user)**：
  - 数据查看：读写权限
  - 文件上传：读写权限
  - 报表生成：只读权限
  - 其他：无权限
- **访客 (guest)**：
  - 数据查看：只读权限
  - 其他：无权限

## 使用方法

1. **访问权限矩阵**：
   - 登录系统后，在仪表板页面点击"权限矩阵"功能卡片
   - 或直接访问 `/permission-matrix` 路径

2. **修改权限**：
   - 在权限矩阵表格中找到要修改的角色和资源交叉点
   - 点击下拉选择框，选择新的权限级别
   - 权限变更会实时生效

3. **保存权限配置**：
   - 点击页面右上角的"保存权限"按钮
   - 系统会保存当前的权限配置到后端

## 技术实现

### 前端组件

- `PermissionMatrixView.vue`：权限矩阵主页面
- 使用 Element Plus 组件库构建界面
- 响应式设计，支持移动端访问

### 后端API

- `GET /auth/permission-matrix`：获取权限矩阵配置
- `POST /auth/permission-matrix`：保存权限矩阵配置

### 数据结构

```typescript
interface PermissionMatrixData {
  role: string;
  permissions: Record<string, string>;
}
```

## 扩展说明

### 添加新角色

1. 在 `roles` 数组中添加新角色定义
2. 在 `getDefaultPermission` 方法中添加默认权限逻辑
3. 在 `getRoleTagType` 和 `getRoleText` 方法中添加角色显示逻辑

### 添加新资源

1. 在 `resources` 数组中添加新资源定义
2. 在 `getDefaultPermission` 方法中为新资源设置默认权限

### 自定义权限级别

1. 修改权限选择框的选项
2. 更新权限说明部分
3. 调整权限验证逻辑

## 注意事项

- 权限矩阵功能通常只有管理员可以访问
- 权限变更会立即影响用户的访问能力
- 建议在修改权限前备份当前配置
- 权限矩阵数据会持久化存储在后端数据库中
